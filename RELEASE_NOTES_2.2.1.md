# BCS Store 2.2.1 (build label 2.2.0.1)

Rebuilt on MGU Store 0.9.40 by Robert Nisipeanu (GPL-3.0-or-later) with BCS identity.

- Big billboard app cards with Install now / Update now buttons, Wi-Fi signal chip, BCS logo header
- Tabs: Apps, Tools, Updates, USB, Sources, Settings (System page under Settings)
- BCS sources auto-added (add-only, never removes yours); upstream MGU Store source stays for tools/requirements
- BCS Store cannot be removed; upstream "MGU Store" app is hidden and removable
- App id unchanged: bcs_store_2

Not yet tested on a real head unit - publish as pre-release first.
Source: bcs_store_2-2.2.1-source.zip (GPL-3.0 corresponding source).
