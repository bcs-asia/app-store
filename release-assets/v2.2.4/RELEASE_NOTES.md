# BCS Store 2.2.4

Based on MGU Store 0.9.40 by Robert Nisipeanu (GPL-3.0-or-later).

- App id is `bcs_store` again (the id of the 2.1.x Store): installs over 2.1.x as a normal update, and the updater already gives it its key, so Remove, Restart head unit and the Wi-Fi buttons work with no head-unit setup.
- Includes everything from 2.2.0-2.2.3 (billboard cards, ID7/ID8 tags, update-only Updates list, Refresh buttons, "BCS Store" naming, Robert's Store hidden, bcs-develop sources removed, visible "Setup needed" message).
- Cars that tested 2.2.0-2.2.3 (id `bcs_store_2`): remove that entry; set `store_app = bcs_store` (SETUP.md) if the updater was changed to bcs_store_2.

Pre-release first; test on a car running 2.1.x. Source: bcs_store-2.2.4-source.zip.
